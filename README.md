# 14-Tooth Spur Gear CAD Model ⚙️

A complete set of 3D models and 2D engineering drawings for a standard 14-tooth spur gear. This repository contains the source CAD files and export formats suitable for 3D printing, CNC machining, or digital assembly testing.

## Repository Contents

* `/src`: Contains the native CAD files (e.g., `.sldprt`, `.ipt`, `.f3d`).
* `/exports`: Contains universal 3D formats for manufacturing and sharing:
  * `.STEP` / `.STP` (For import into other CAD software)
  * `.STL` (For 3D printing)
  * `.IGES`
* `/drawings`: Contains 2D orthographic wireframe views (Top, Front, Right) in `.pdf` and `.dxf` formats.
* `/images`: Contains visual renders and wireframe screenshots of the gear.
* .dwg
* .pdf
* .png

## How to Use This Model

1. Clone the repository: `git clone https://github.com/yourusername/your-repo-name.git`
2. Import the `.STEP` file into your preferred CAD software, or open the native files in `/src`.
3. For 3D printing, slice the provided `.STL` file located in the `/exports` folder.
